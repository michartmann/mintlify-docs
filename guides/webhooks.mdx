## Overview

ADCB webhooks provide real-time notifications when events occur in your customers' accounts or transactions. This eliminates the need for constant polling and enables you to build responsive applications that react immediately to banking events.

<Info>
  Webhooks are HTTP callbacks sent to your application when specific events occur. They're essential for building real-time financial applications.
</Info>

### Step 2: Implement Webhook Endpoint

<CodeGroup>

```python Flask
from flask import Flask, request, jsonify
import hmac
import hashlib
import json

app = Flask(__name__)
WEBHOOK_SECRET = "your_webhook_secret_key"

def verify_signature(payload, signature, secret):
    """Verify webhook signature"""
    expected = hmac.new(
        secret.encode(),
        payload,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)

@app.route('/webhooks/adcb', methods=['POST'])
def handle_webhook():
    # Get signature from headers
    signature = request.headers.get('X-ADCB-Signature')
    if not signature:
        return jsonify({'error': 'Missing signature'}), 401
    
    # Verify signature
    payload = request.get_data()
    if not verify_signature(payload, signature, WEBHOOK_SECRET):
        return jsonify({'error': 'Invalid signature'}), 401
    
    # Process webhook
    event = request.json
    event_type = event.get('type')
    
    if event_type == 'transaction.completed':
        handle_transaction_completed(event['data'])
    elif event_type == 'payment.initiated':
        handle_payment_initiated(event['data'])
    elif event_type == 'account.balance.updated':
        handle_balance_updated(event['data'])
    
    return jsonify({'status': 'success'}), 200

def handle_transaction_completed(data):
    print(f"Transaction completed: {data['transaction_id']}")
    # Process transaction completion
    
def handle_payment_initiated(data):
    print(f"Payment initiated: {data['payment_id']}")
    # Process payment initiation
    
def handle_balance_updated(data):
    print(f"Balance updated for account: {data['account_id']}")
    # Process balance update
```

```javascript Express
const express = require('express');
const crypto = require('crypto');
const app = express();

const WEBHOOK_SECRET = 'your_webhook_secret_key';

// Middleware to capture raw body
app.use('/webhooks/adcb', express.raw({ type: 'application/json' }));

function verifySignature(payload, signature, secret) {
    const expected = crypto
        .createHmac('sha256', secret)
        .update(payload)
        .digest('hex');
    return crypto.timingSafeEqual(
        Buffer.from(signature),
        Buffer.from(`sha256=${expected}`)
    );
}

app.post('/webhooks/adcb', (req, res) => {
    const signature = req.headers['x-adcb-signature'];
    
    if (!signature) {
        return res.status(401).json({ error: 'Missing signature' });
    }
    
    if (!verifySignature(req.body, signature, WEBHOOK_SECRET)) {
        return res.status(401).json({ error: 'Invalid signature' });
    }
    
    const event = JSON.parse(req.body);
    const eventType = event.type;
    
    switch (eventType) {
        case 'transaction.completed':
            handleTransactionCompleted(event.data);
            break;
        case 'payment.initiated':
            handlePaymentInitiated(event.data);
            break;
        case 'account.balance.updated':
            handleBalanceUpdated(event.data);
            break;
        default:
            console.log(`Unhandled event type: ${eventType}`);
    }
    
    res.json({ status: 'success' });
});

function handleTransactionCompleted(data) {
    console.log(`Transaction completed: ${data.transaction_id}`);
    // Process transaction completion
}

function handlePaymentInitiated(data) {
    console.log(`Payment initiated: ${data.payment_id}`);
    // Process payment initiation
}

function handleBalanceUpdated(data) {
    console.log(`Balance updated for account: ${data.account_id}`);
    // Process balance update
}

app.listen(3000, () => {
    console.log('Webhook server running on port 3000');
});
```

## Security Best Practices

### Signature Verification

<Warning>
  Always verify webhook signatures to ensure requests are from ADCB. Never process unverified webhooks.
</Warning>

ADCB signs all webhook payloads using HMAC SHA-256:

```python
import hmac
import hashlib

def verify_webhook_signature(payload, signature, secret):
    """Verify ADCB webhook signature"""
    # Remove 'sha256=' prefix from signature
    received_signature = signature.replace('sha256=', '')
    
    # Calculate expected signature
    expected_signature = hmac.new(
        secret.encode('utf-8'),
        payload.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()
    
    # Use constant-time comparison
    return hmac.compare_digest(received_signature, expected_signature)

# Example usage
payload = request.get_data(as_text=True)
signature = request.headers.get('X-ADCB-Signature')
secret = 'your_webhook_secret'

if verify_webhook_signature(payload, signature, secret):
    # Process webhook
    process_webhook(payload)
else:
    # Reject webhook
    return 'Invalid signature', 401
```

<Info>

- Use valid SSL certificates
- Support TLS 1.2 or higher
- Ensure proper certificate chain

## Retry Logic and Reliability

### ADCB Retry Behavior

ADCB will retry failed webhooks with exponential backoff:

- **Immediate retry** after initial failure
- **30 seconds** after first retry
- **5 minutes** after second retry  
- **1 hour** after third retry
- **6 hours** after fourth retry
- **24 hours** for final attempts

### Response Requirements

Your webhook endpoint must:

- Respond within **30 seconds**
- Return HTTP status **200** for success
- Return **4xx** for permanent failures (won't retry)
- Return **5xx** for temporary failures (will retry)

```python
@app.route('/webhooks/adcb', methods=['POST'])
def handle_webhook():
    try:
        event = request.json
        process_event(event)
        return jsonify({'status': 'success'}), 200
    except ValidationError as e:
        # Permanent error - don't retry
        return jsonify({'error': str(e)}), 400
    except TemporaryError as e:
        # Temporary error - retry
        return jsonify({'error': str(e)}), 503
```

## Monitoring and Debugging

### Webhook Logs

Monitor webhook delivery in the developer portal:

- **Delivery Status**: Success/failure rates
- **Response Times**: Endpoint performance
- **Error Details**: Failure reasons and codes
- **Retry History**: Retry attempts and outcomes

### Common Issues

<AccordionGroup>
  <Accordion title="Webhook Timeouts">
    **Symptoms**: Webhooks marked as failed due to timeouts
    
    **Solutions**:
    - Optimize endpoint response time
    - Process webhooks asynchronously
    - Use background job queues
    - Return 200 immediately, process later
  </Accordion>
  
  <Accordion title="Signature Verification Failures">
    **Symptoms**: 401 errors, signature mismatches
    
    **Solutions**:
    - Check webhook secret configuration
    - Verify payload encoding (UTF-8)
    - Use raw request body for verification
    - Check for middleware modifying payload
  </Accordion>
  
  <Accordion title="Duplicate Events">
    **Symptoms**: Same event received multiple times
    
    **Solutions**:
    - Implement idempotency using event IDs
    - Check for retry logic conflicts
    - Use database constraints to prevent duplicates
    - Log event IDs for tracking
  </Accordion>
</AccordionGroup>
