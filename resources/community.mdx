    ```python
    # Popular: Account balance aggregation
    async def get_total_balance(customer_id):
        accounts = await adcb_client.get_accounts(customer_id)
        total = sum(float(account['balance']['available']['amount']) 
                   for account in accounts['data'])
        return {'total_balance': total, 'currency': 'AED'}
    ```
    
    ```javascript
    // Popular: Payment status monitoring
    const monitorPayment = (paymentId) => {
      const checkStatus = async () => {
        const payment = await adcbClient.getPaymentStatus(paymentId);
        if (payment.status === 'completed') {
          console.log('Payment successful!');
          return payment;
        }
        setTimeout(checkStatus, 2000); // Check every 2 seconds
      };
      return checkStatus();
    };
    ```

## Community Guidelines

### 📋 Code of Conduct

**Be Respectful**
- Treat all community members with respect and professionalism
- Welcome newcomers and help them learn
- Avoid discriminatory language or behavior

**Be Helpful**
- Share knowledge generously
- Provide constructive feedback
- Help others troubleshoot issues

**Be Professional**
- Keep discussions technical and on-topic
- Respect intellectual property
- Follow security best practices

### 🛡️ Moderation Policy

Our community moderators ensure a positive environment:
- **Warning**: First offense gets a friendly reminder
- **Temporary ban**: Repeated violations result in 7-day suspension
- **Permanent ban**: Serious violations or repeated offenses

**Report Issues**: Use `@moderator` in Discord or email community@adcb.com
