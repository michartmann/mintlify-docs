## Getting Help

### Before Contacting Support

<Steps>
  <Step title="Check API Status">
    Visit [status.adcb.dev](https://status.adcb.dev) to check for known issues
  </Step>
  <Step title="Search Documentation">
    Review our comprehensive documentation and troubleshooting guides
  </Step>
  <Step title="Check Community Forum">
    See if your question has already been answered in our community forum
  </Step>
  <Step title="Review Error Messages">
    Gather detailed error messages and trace IDs from API responses
  </Step>
</Steps>

### Information to Provide

When contacting support, please include:

<AccordionGroup>
  <Accordion title="Technical Details">
    - **API Endpoint**: Which specific endpoint(s) are affected
    - **HTTP Method**: GET, POST, PUT, DELETE, etc.
    - **Request Headers**: Include all relevant headers (mask sensitive data)
    - **Request Body**: Sample request payload (mask sensitive data)
    - **Response**: Full error response including status code
    - **Trace ID**: From X-Trace-ID header in the response
    - **Timestamp**: When the issue occurred (include timezone)
  </Accordion>
  
  <Accordion title="Environment Information">
    - **Environment**: Sandbox or Production
    - **Client ID**: Your application's client ID
    - **SDK Version**: If using official SDKs
    - **Programming Language**: And version
    - **Server Location**: Geographic location of your servers
  </Accordion>
  
  <Accordion title="Business Context">
    - **Impact**: How many users/transactions are affected
    - **Urgency**: Business impact and required resolution timeframe
    - **Frequency**: Is this a one-time or recurring issue
    - **Recent Changes**: Any recent changes to your integration
  </Accordion>
</AccordionGroup>

### Sample Support Request

```
Subject: [CRITICAL] Payment API returning 500 errors - Production

Environment: Production
Affected Endpoint: POST /v1/payments
Client ID: prod_client_12345

Issue Description:
Payment initiation requests are returning 500 Internal Server Error 
since 14:30 GST today. Approximately 50 payment requests have failed.

Technical Details:
- HTTP Status: 500
- Error Response: {"error": {"type": "internal_error", "detail": "Unexpected server error"}}
- Trace IDs: 4d9c8b5a-f6e2-4c8a-9d3b-1e7f5a6c8d9e, 7f8e9d0c-1234-5678-9abc-def012345678
- First Occurrence: 2024-01-15 14:30:15 GST
- Frequency: 100% failure rate since 14:30

Business Impact:
- 50 customers unable to make payments
- Critical business functionality affected
- Urgent resolution required

Recent Changes:
No changes to our integration in the past 2 weeks.

Request immediate investigation and resolution.
```

## Escalation Process

If you're not satisfied with the initial response:

<Steps>
  <Step title="Request Escalation">
    Reply to your support ticket requesting escalation to a senior engineer
  </Step>
  <Step title="Manager Review">
    Your case will be reviewed by the Support Manager within 2 hours
  </Step>
  <Step title="Technical Lead Involvement">
    If needed, the Technical Lead will be brought into the investigation
  </Step>
  <Step title="Executive Escalation">
    For critical business impact, escalate to api-escalation@adcb.com
  </Step>
</Steps>
