## Step 2: Obtain Access Token

Use OAuth 2.0 client credentials flow to get an access token:

<CodeGroup>

```bash cURL
curl -X POST https://api.adcb.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --cert your-mtls-cert.pem \
  --key your-mtls-key.pem \
  -d "grant_type=client_credentials" \
  -d "client_id=YOUR_CLIENT_ID" \
  -d "client_secret=YOUR_CLIENT_SECRET" \
  -d "scope=accounts:read payments:write"
```

```python Python
import requests

token_url = "https://api.adcb.com/oauth/token"
client_id = "YOUR_CLIENT_ID"
client_secret = "YOUR_CLIENT_SECRET"

response = requests.post(
    token_url,
    data={
        "grant_type": "client_credentials",
        "client_id": client_id,
        "client_secret": client_secret,
        "scope": "accounts:read payments:write"
    },
    cert=('your-mtls-cert.pem', 'your-mtls-key.pem')
)

access_token = response.json()["access_token"]
print(f"Access Token: {access_token}")
```

```javascript Node.js
const axios = require('axios');
const fs = require('fs');
const https = require('https');

const agent = new https.Agent({
  cert: fs.readFileSync('your-mtls-cert.pem'),
  key: fs.readFileSync('your-mtls-key.pem')
});

const getAccessToken = async () => {
  const response = await axios.post(
    'https://api.adcb.com/oauth/token',
    {
      grant_type: 'client_credentials',
      client_id: 'YOUR_CLIENT_ID',
      client_secret: 'YOUR_CLIENT_SECRET',
      scope: 'accounts:read payments:write'
    },
    { 
      httpsAgent: agent,
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' }
    }
  );
  
  return response.data.access_token;
};
```

</CodeGroup>

<Note>
  Access tokens expire after 3600 seconds (1 hour). Implement token refresh logic in your production code.
</Note>

## Step 3: Make Your First API Call

Now let's retrieve account information using the access token:

<CodeGroup>

```bash cURL
curl -X GET https://api.adcb.com/v1/accounts \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Accept: application/json" \
  -H "X-Request-ID: unique-request-id-123" \
  --cert your-mtls-cert.pem \
  --key your-mtls-key.pem
```

```python Python
headers = {
    "Authorization": f"Bearer {access_token}",
    "Accept": "application/json",
    "X-Request-ID": "unique-request-id-123"
}

response = requests.get(
    "https://api.adcb.com/v1/accounts",
    headers=headers,
    cert=('your-mtls-cert.pem', 'your-mtls-key.pem')
)

accounts = response.json()
print(f"Accounts: {accounts}")
```

```javascript Node.js
const getAccounts = async (accessToken) => {
  const response = await axios.get(
    'https://api.adcb.com/v1/accounts',
    {
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Accept': 'application/json',
        'X-Request-ID': 'unique-request-id-123'
      },
      httpsAgent: agent
    }
  );
  
  return response.data;
};
```

</CodeGroup>

<Accordion title="Security Requirements">
  - [ ] Implement mTLS with production certificates
  - [ ] Store credentials securely (use HSM or key vault)
  - [ ] Implement request signing (JWS)
  - [ ] Set up IP whitelisting

<Accordion title="Error Handling">
  - [ ] Implement exponential backoff for retries
  - [ ] Handle all HTTP status codes appropriately
  - [ ] Log errors with correlation IDs
  - [ ] Set up monitoring and alerting
</Accordion>

<Accordion title="Compliance">
  - [ ] Data retention policies in place
  - [ ] GDPR/data privacy compliance
  - [ ] Customer consent management
  - [ ] Transaction monitoring for AML
</Accordion>

## Common Issues and Solutions

<AccordionGroup>
  <Accordion title="401 Unauthorized Error">
    **Causes:**
    - Expired access token
    - Invalid credentials
    - Wrong environment (sandbox vs production)
    
    **Solution:**
    - Refresh your access token
    - Verify client credentials
    - Check you're using correct base URL
  </Accordion>
  
  <Accordion title="403 Forbidden Error">
    **Causes:**
    - Missing required scopes
    - IP not whitelisted
    - Invalid mTLS certificate
    
    **Solution:**
    - Request appropriate scopes during token generation
    - Add your IP to whitelist in dashboard
    - Ensure mTLS certificate is valid and not expired
  </Accordion>
  
  <Accordion title="429 Rate Limit Exceeded">
    **Causes:**
    - Too many requests in time window
    
    **Solution:**
    - Implement rate limiting on client side
    - Use exponential backoff
    - Check X-RateLimit headers for limits
  </Accordion>
</AccordionGroup>
