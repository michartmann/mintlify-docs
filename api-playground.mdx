Test ADCB APIs instantly without writing any code. Our interactive playground provides a safe sandbox environment with realistic test data.

<Warning>
🔒 **Sandbox Environment**: All requests use test data. No real transactions will be processed.

## 🔐 Authenticated Endpoints

### Get Account Balance

<CodeGroup>
```bash Request
curl -X GET "https://sandbox-api.adcb.com/v1/accounts/ACC123456789/balance" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "X-Request-ID: unique-request-id"
```

```python Python
import requests

response = requests.get(
    "https://sandbox-api.adcb.com/v1/accounts/ACC123456789/balance",
    headers={
        "Authorization": "Bearer YOUR_ACCESS_TOKEN",
        "X-Request-ID": "unique-request-id"
    }
)

print(response.json())
```

```javascript Node.js
const axios = require('axios');

const response = await axios.get(
  'https://sandbox-api.adcb.com/v1/accounts/ACC123456789/balance',
  {
    headers: {
      'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
      'X-Request-ID': 'unique-request-id'
    }
  }
);

console.log(response.data);
```
</CodeGroup>

## 🧪 Test Scenarios

### Common Test Cases

<AccordionGroup>
  <Accordion title="Successful Payment Flow">
    ```javascript
    // Step 1: Create payment consent
    const consent = await createPaymentConsent({
      amount: 100.00,
      currency: "AED",
      fromAccount: "ACC123456789",
      toAccount: "ACC987654321"
    });
    
    // Step 2: Authorize consent (automatic in sandbox)
    const authorization = await authorizeConsent(consent.consentId);
    
    // Step 3: Execute payment
    const payment = await executePayment({
      consentId: consent.consentId,
      authorization: authorization.token
    });
    
    console.log("Payment completed:", payment.paymentId);
    ```
  </Accordion>
  
  <Accordion title="Error Handling Test">
    Test various error scenarios:
    - Invalid authentication (401)
    - Insufficient funds (400)
    - Rate limit exceeded (429)
    - Server error simulation (500)
    
    Use `X-Test-Scenario` header to trigger specific errors:
    ```bash
    curl -H "X-Test-Scenario: insufficient_funds"
    ```
  </Accordion>
  
  <Accordion title="Webhook Testing">
    ```javascript
    // Register webhook endpoint
    const webhook = await registerWebhook({
      url: "https://your-app.com/webhooks",
      events: ["payment.completed", "account.updated"],
      secret: "your-webhook-secret"
    });
    
    // Trigger test webhook
    await triggerTestWebhook({
      webhookId: webhook.id,
      event: "payment.completed",
      data: { paymentId: "PAY123", amount: 100.00 }
    });
    ```
  </Accordion>
</AccordionGroup>
