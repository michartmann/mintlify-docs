## Integration Guide

### Step 1: Authentication

CDP APIs require enhanced authentication:

```bash
curl -X POST https://api.adcb.com/cdp/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=YOUR_CDP_CLIENT_ID" \
  -d "client_secret=YOUR_CDP_CLIENT_SECRET" \
  -d "scope=cdp:read analytics:read"
```

### Step 2: Query Customer Data

```python
import requests

headers = {
    "Authorization": f"Bearer {access_token}",
    "X-Consent-ID": "CONS123456"
}

# Get customer profile
response = requests.get(
    "https://api.adcb.com/cdp/v1/customers/CUST123456",
    headers=headers
)

customer_data = response.json()
```

### Step 3: Subscribe to Events

```python
# Subscribe to customer events
subscription = cdp_client.subscribe_events({
    "customer_id": "CUST123456",
    "events": [
        "profile_update",
        "transaction_completed",
        "product_activated"
    ],
    "webhook_url": "https://yourapp.com/webhooks/cdp"
})
```

## Privacy and Compliance

<Warning>
  All CDP API access requires explicit customer consent. Ensure you:
  - Obtain proper consent before accessing customer data
  - Implement data minimization principles
  - Comply with GDPR and UAE data protection laws
  - Maintain audit logs of all data access
</Warning>

### Consent Management

```python
# Check consent status
consent = cdp_client.get_consent_status(
    customer_id="CUST123456",
    purpose="marketing_analytics"
)

if consent.status == "active":
    # Proceed with data access
    data = cdp_client.get_customer_insights(customer_id)
else:
    # Request consent through appropriate channel
    pass
```

## Rate Limits

CDP APIs have specific rate limits to ensure platform stability:

- **Profile APIs**: 100 requests/minute
- **Analytics APIs**: 50 requests/minute
- **Bulk Operations**: 10 requests/hour

## Best Practices

<AccordionGroup>
  <Accordion title="Data Caching">
    Cache frequently accessed data to reduce API calls:
    - Customer profiles: 15-minute TTL
    - Analytics results: 1-hour TTL
    - Segments: 24-hour TTL
  </Accordion>
  
  <Accordion title="Batch Processing">
    Use batch endpoints for bulk operations:
    ```python
    # Batch customer query
    customers = cdp_client.batch_get_customers(
        customer_ids=["CUST1", "CUST2", "CUST3"],
        fields=["profile", "scores", "segments"]
    )
    ```
  </Accordion>
  
  <Accordion title="Event Streaming">
    Implement webhooks for real-time updates instead of polling:
    ```python
    @app.route('/webhooks/cdp', methods=['POST'])
    def handle_cdp_event():
        event = request.json
        if event['type'] == 'profile_updated':
            # Invalidate cache and fetch new data
            cache.delete(f"customer:{event['customer_id']}")
    ```
  </Accordion>
</AccordionGroup>
