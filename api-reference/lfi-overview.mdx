## Overview

ADCB's Open Finance APIs for Licensed Financial Institutions (LFIs) provide advanced integration capabilities beyond standard TPP access. These APIs are designed for banks, insurance companies, and other licensed financial institutions requiring deeper integration with ADCB's systems.

## Headless Authentication (Heimdall)

### White-Label Authentication Flow

Integrate ADCB's authentication seamlessly into your application:

```javascript
// Initialize headless auth
const auth = new ADCBHeadlessAuth({
    clientId: 'LFI_CLIENT_ID',
    environment: 'production',
    theme: {
        primaryColor: '#003366',
        logo: 'https://yourlfi.com/logo.png'
    }
});

// Trigger authentication
const session = await auth.authenticate({
    username: 'customer@email.com',
    method: 'biometric',
    context: {
        deviceId: 'device-uuid',
        location: 'Dubai, UAE',
        ipAddress: '192.168.1.1'
    }
});

// Handle MFA if required
if (session.requiresMFA) {
    const mfaResult = await auth.completeMFA({
        sessionId: session.id,
        method: 'SMS',
        code: '123456'
    });
}
```

## Event Streaming API

### Real-Time Event Subscriptions

<CodeGroup>

```python Python
# Subscribe to events
subscription = lfi_client.events.subscribe({
    "events": [
        "account.balance.changed",
        "transaction.completed",
        "payment.initiated",
        "consent.revoked",
        "customer.profile.updated"
    ],
    "filters": {
        "accounts": ["AE070331234567890123456"],
        "minAmount": 1000
    },
    "delivery": {
        "method": "webhook",
        "url": "https://yourlfi.com/webhooks/adcb",
        "secret": "webhook_secret_key"
    }
})

# Handle incoming events
@app.route('/webhooks/adcb', methods=['POST'])
def handle_event():
    event = verify_webhook_signature(request)
    
    if event['type'] == 'transaction.completed':
        process_transaction(event['data'])
    elif event['type'] == 'consent.revoked':
        handle_consent_revocation(event['data'])
```

```javascript WebSocket
// Real-time WebSocket connection
const ws = new WebSocket('wss://api.adcb.com/lfi/events');

ws.on('open', () => {
    ws.send(JSON.stringify({
        action: 'subscribe',
        token: accessToken,
        events: ['account.balance.changed', 'transaction.completed']
    }));
});

ws.on('message', (data) => {
    const event = JSON.parse(data);
    console.log(`Event received: ${event.type}`, event.data);
    
    // Process event in real-time
    processEvent(event);
});
```

</CodeGroup>

### Event Types

<AccordionGroup>
  <Accordion title="Account Events">
    - `account.opened` - New account created
    - `account.closed` - Account closed
    - `account.balance.changed` - Balance update
    - `account.status.changed` - Status change (frozen, active, etc.)
    - `account.limit.exceeded` - Limit breach notification
  </Accordion>
  
  <Accordion title="Transaction Events">
    - `transaction.completed` - Transaction processed
    - `transaction.failed` - Transaction failed
    - `transaction.reversed` - Transaction reversal
    - `transaction.disputed` - Dispute raised
    - `transaction.suspicious` - Fraud alert
  </Accordion>
  
  <Accordion title="Customer Events">
    - `customer.onboarded` - New customer
    - `customer.profile.updated` - Profile change
    - `customer.kyc.expired` - KYC renewal needed
    - `customer.risk.changed` - Risk rating update
  </Accordion>
</AccordionGroup>

## Bank Data Sharing API

### Bi-Directional Data Exchange

Share and receive data with ADCB for enhanced services:

```python
# Share customer data with ADCB
sharing_agreement = lfi_client.data_sharing.create_agreement({
    "type": "BIDIRECTIONAL",
    "dataCategories": [
        "credit_history",
        "income_verification",
        "asset_information"
    ],
    "purpose": "Joint lending assessment",
    "duration": "6_months",
    "reciprocalSharing": True
})

# Upload data
lfi_client.data_sharing.upload({
    "agreementId": sharing_agreement.id,
    "customerId": "CUST789012",
    "data": {
        "creditScore": 750,
        "monthlyIncome": 25000,
        "employmentStatus": "EMPLOYED",
        "employmentDuration": "5_years"
    }
})

# Retrieve ADCB data
adcb_data = lfi_client.data_sharing.retrieve({
    "agreementId": sharing_agreement.id,
    "customerId": "CUST789012",
    "dataTypes": ["account_history", "payment_behavior"]
})
```

## Service Initiation API

### Complex Service Orchestration

Initiate and manage complex multi-step services:

```python
# Initiate loan application with multiple services
service = lfi_client.services.initiate({
    "serviceType": "JOINT_LOAN_APPLICATION",
    "participants": [
        {"customerId": "CUST123456", "role": "PRIMARY"},
        {"customerId": "CUST789012", "role": "CO_APPLICANT"}
    ],
    "workflow": {
        "steps": [
            {
                "id": "credit_check",
                "service": "CREDIT_BUREAU_CHECK",
                "parallel": True
            },
            {
                "id": "income_verification",
                "service": "SALARY_VERIFICATION",
                "parallel": True
            },
            {
                "id": "property_valuation",
                "service": "PROPERTY_ASSESSMENT",
                "dependsOn": ["credit_check", "income_verification"]
            },
            {
                "id": "final_approval",
                "service": "UNDERWRITING",
                "dependsOn": ["property_valuation"]
            }
        ]
    },
    "callback": "https://yourlfi.com/services/callback"
})

# Monitor service progress
progress = lfi_client.services.get_progress(service.id)
for step in progress.steps:
    print(f"{step.id}: {step.status} - {step.completion}%")
```
