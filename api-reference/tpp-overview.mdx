## Overview

ADCB's Open Finance APIs for Third-Party Providers (TPPs) enable licensed institutions to access banking services in compliance with CBUAE Open Banking regulations. These APIs support Account Information Service Providers (AISPs) and Payment Initiation Service Providers (PISPs) in delivering innovative financial services.

### Example: Retrieving Account Information

<CodeGroup>

```python Python
# Step 1: Create consent
consent = tpp_client.create_consent({
    "permissions": [
        "ReadAccountsBasic",
        "ReadAccountsDetail",
        "ReadBalances",
        "ReadTransactionsBasic",
        "ReadTransactionsDetail"
    ],
    "expirationDateTime": "2024-12-31T23:59:59Z",
    "transactionFromDateTime": "2024-01-01T00:00:00Z",
    "transactionToDateTime": "2024-12-31T23:59:59Z"
})

# Step 2: Get authorization from customer
auth_url = tpp_client.get_authorization_url(consent.id)
# Redirect customer to auth_url

# Step 3: Exchange authorization code for access token
token = tpp_client.exchange_code(authorization_code)

# Step 4: Access account data
accounts = tpp_client.get_accounts(token)
for account in accounts:
    balance = tpp_client.get_balance(token, account.id)
    transactions = tpp_client.get_transactions(
        token, 
        account.id,
        from_date="2024-01-01",
        to_date="2024-01-31"
    )
```

## Confirmation of Payee (CoP)

Verify beneficiary details before payment to prevent fraud:

```python
# Verify beneficiary
cop_result = tpp_client.verify_payee({
    "account": {
        "schemeName": "IBAN",
        "identification": "AE070339876543210987654"
    },
    "name": "Mohammed Ali Hassan"
})

if cop_result.match == "FULL":
    # Name matches exactly - safe to proceed
    submit_payment()
elif cop_result.match == "PARTIAL":
    # Partial match - request confirmation
    show_warning(f"Name on account: {cop_result.actualName}")
elif cop_result.match == "NO_MATCH":
    # No match - high fraud risk
    block_payment()
```

## Consent Management

### Consent Lifecycle

<Info>
  All data access requires explicit customer consent with defined scope and duration
</Info>

```python
# Create consent request
consent = tpp_client.create_consent({
    "permissions": ["ReadAccountsDetail", "ReadBalances"],
    "expirationDateTime": "2024-06-30T23:59:59Z",
    "transactionFromDateTime": "2023-01-01T00:00:00Z",
    "transactionToDateTime": "2024-06-30T23:59:59Z"
})

# Check consent status
status = tpp_client.get_consent_status(consent.id)
print(f"Consent status: {status.status}")  # Active, Expired, Revoked

# Revoke consent
tpp_client.revoke_consent(consent.id)
```

## Regulatory Compliance

### CBUAE Requirements

<Warning>
  TPPs must comply with all CBUAE Open Banking regulations:
  - Valid TPP license required
  - Customer consent mandatory
  - Data retention limits apply
  - Regular compliance audits
</Warning>

### Security Standards

- **PSD2/Open Banking compliant**: Following international standards
- **mTLS mandatory**: All connections require mutual TLS
- **Message signing**: JWS signatures for payment instructions
- **Qualified certificates**: eIDAS/CBUAE approved certificates only
