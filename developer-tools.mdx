## Quick Development Setup

<Steps>
  <Step title="Get API Credentials">
    Register at the [Developer Portal](https://developers.adcb.com) and obtain your API keys
  </Step>
  <Step title="Configure Authentication">
    Set up mTLS certificates and OAuth 2.0 for secure API access
    ```bash
    # Install certificates
    curl -o adcb-cert.pem https://developers.adcb.com/certs/sandbox.pem
    ```
  </Step>
  <Step title="Choose Your SDK">
    Install the official SDK for your preferred language
    ```bash
    # Python
    pip install adcb-openbanking-sdk
    
    # Node.js  
    npm install @adcb/openbanking-sdk
    ```
  </Step>
  <Step title="Make Your First API Call">
    Test connectivity with a simple account information request
  </Step>
</Steps>

## Testing & Debugging Tools

### API Response Validator

Validate API responses against OpenAPI specifications:

```bash
# Install validator
npm install -g @adcb/api-validator

# Validate response
adcb-validator --endpoint "/accounts" --response response.json
```

### Rate Limit Monitor

Monitor your API usage and rate limits:

```python
from adcb_sdk import RateLimitMonitor

monitor = RateLimitMonitor(api_key="your-key")
usage = monitor.get_current_usage()
print(f"Requests remaining: {usage['remaining']}")
```

### Circuit Breaker Pattern

Implement resilient API calls:

```javascript
const CircuitBreaker = require('adcb-circuit-breaker');

const breaker = new CircuitBreaker(adcbApi.getAccounts, {
  timeout: 3000,
  errorThresholdPercentage: 50,
  resetTimeout: 30000
});

breaker.fallback(() => 'Service temporarily unavailable');
```

## Performance Optimization

### Connection Pooling

```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

session = requests.Session()
retry = Retry(total=3, backoff_factor=0.3)
adapter = HTTPAdapter(max_retries=retry, pool_connections=10, pool_maxsize=20)

session.mount('https://', adapter)
```

### Response Caching

```javascript
const NodeCache = require('node-cache');
const cache = new NodeCache({ stdTTL: 300 }); // 5 minute cache

function getCachedAccounts(customerId) {
  const cacheKey = `accounts_${customerId}`;
  let accounts = cache.get(cacheKey);
  
  if (!accounts) {
    accounts = adcbApi.getAccounts(customerId);
    cache.set(cacheKey, accounts);
  }
  
  return accounts;
}
```

## Monitoring & Observability

### Health Check Endpoint

```bash
# Check API health
curl -X GET "https://api.adcb.com/health" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

### Metrics Collection

```python
import time
from prometheus_client import Counter, Histogram

api_requests_total = Counter('adcb_api_requests_total', 'Total API requests', ['method', 'endpoint'])
api_request_duration = Histogram('adcb_api_request_duration_seconds', 'API request duration')

def track_api_call(func):
    def wrapper(*args, **kwargs):
        start_time = time.time()
        try:
            result = func(*args, **kwargs)
            api_requests_total.labels(method='GET', endpoint='/accounts').inc()
            return result
        finally:
            api_request_duration.observe(time.time() - start_time)
    return wrapper
```
